# Documentation

Project documentation and technical specifications.

## Purpose

Contains all project documentation including:

- Final year project report
- Technical specifications
- API documentation
- Architecture diagrams
- Setup guides
- Research papers and references

## Structure

- `report/` - Final year project report (LaTeX/Markdown)
- `api/` - Auto-generated API documentation
- `architecture/` - System architecture diagrams and descriptions
- `setup/` - Installation and deployment guides

## Usage

Documentation is maintained in Markdown format. API docs are auto-generated from code comments.
