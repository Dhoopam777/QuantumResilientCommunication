# Desktop Application

Electron-based desktop client for the Quantum-Resilient Communication System.

## Purpose

Provides a native desktop experience for secure communication with offline capabilities.

## Technology Stack

- Electron
- React
- TypeScript
- Electron Builder (packaging)

## Structure

- `src/` - Main process and renderer code
- `build/` - Build artifacts and installers

## Setup

1. Install dependencies: `npm install`
2. Start development: `npm run dev`
3. Build application: `npm run build`
