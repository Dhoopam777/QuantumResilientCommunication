# Web Application

React-based web frontend for the Quantum-Resilient Communication System.

## Purpose

Provides the user interface for secure messaging, real-time communication, and system interaction.

## Technology Stack

- React 18+
- TypeScript
- Vite (build tool)
- Tailwind CSS (styling)
- React Router (navigation)
- Axios (API client)

## Structure

- `src/` - Source code
- `public/` - Static assets
- `dist/` - Build output

## Setup

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build for production: `npm run build`
